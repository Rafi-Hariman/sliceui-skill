Executive Summary

SliceUI memiliki dua jalur parsing XML yang divergen, fidelity metric yang menyesatkan, dan serangkaian field desain kritis yang hilang sebelum mencapai coding agent — tetapi fondasi parsing-nya aman, deterministik, dan scalable.

Temuan terverifikasi (paling kritis)

  • Format FigML tidak lossless. Vocabulary tag-nya terbuka — nama layer Figma menjadi nama tag XML (Button_FNC, search_bar, Icon_white). Tanpa XSD/namespace. Hanya 2 export asli yang tersedia sebagai bukti.
  • Dua parser paralel divergen (src/lib/figml-parse.mjs "lossy" vs src/design/raw-graph.mjs "lossless") — keduanya memakai fast-xml-parser, tapi tidak ada kontrak bersama, dan keduanya membuang mainComponent.id (relasi component→instance).
  • Fidelity "100%" menyesatkan. computeFidelity hanya menskor 13 atribut kurasi (fidelity.mjs:32-36); field yang hilang (font family, opacity, sizing, alignment, constraints, mainComponent) tidak ada di denominator.
  • P0 usable 84.6%, P1 usable 47.1%. Fondasi (teks/geometri/warna/border/radius) solid; responsive & typography bocor.
  • Parser XML aman: XXE, depth-bomb, prototype-pollution, dan malformed semuanya diblokir fast-xml-parser (dibuktikan empiris).
  • Prompt injection terbuka: nama layer & teks tersalur verbatim ke prompt agent tanpa isolasi teknis (hanya larangan di SKILL.md:62).
Rekomendasi utama: Pilihan B — FigML → versioned adapter → SliceIR → scene index → hierarchical transcript. Bukan refactor besar; perubahan minimum yang dibuktikan oleh field-coverage.

Skema FigML Empiris

Diinventaris dari 2 export asli (mahasiswa-tarif/raw.xml 120 KB, tester.xml 170 KB). Detail lengkap di observed-figml-schema.json.

Fakta struktural terverifikasi

  • Root: <frame> (lowercase); frame anak: <Frame> (capital) — inkonsistensi case. (observed-figml-schema.md §2)
  • Deklarasi versi: <?figml version="1.0"?> — tidak dibaca oleh parser (tidak ada gate versi).
  • Tag instance = nama layer Figma (vocabulary terbuka). Tidak ada DTD/XSD/namespace.
  • Warna hanya #rrggbb (tanpa alpha) di fixture; opacity node decimal presisi penuh Figma.
  • Nilai numerik bercampur tipe: fontWeight/cornerRadius bisa "", koordinat desimal sub-pixel.

Elemen metadata yang di-skip oleh parser

SKIP_TAGS (figml-parse.mjs:122-126): constraints, fontName, letterSpacing, fill, lineHeight, overrides, override, overriddenFields, overriddenField, mainComponent, componentProperties, variantProperties, textStyles.

Sebagian dibaca dari child (lineHeight/letterSpacing/fill), sebagian dibaca sebagian (variantProperties → Type/Name/required), sebagian dibuang total (constraints, mainComponent, fontName.family).

Implementation Plan (perubahan minimum, fase berikutnya)

  1. Ekspos mainComponent.id sebagai componentId (P0, paling berdampak).
  2. Salurkan fontName.family → style.family + tokens.fonts (P1).
  3. Salurkan layoutSizingH/V, alignPrimary/Counter, layoutPositioning, constraints (P1 responsive).
  4. Salurkan opacity non-zero sebagai node.opacity (schema sudah punya field).
  5. Salurkan required ke inspect/spec (bukan hanya hidden-asterisk).
  6. Gate schemaVersion baca ?figml version.
  7. Chunking per Page/Section/Frame + dedup instance untuk scale.
  8. Delimitasi data desain (prompt-injection isolation).

Limitasi

  • Basis skema = 2 export FIGML asli + 2 XML buatan tangan; tidak mewakili seluruh fitur Figma (gradient/image/shadow/variable/RTL/rotation/rich-text tak teramati).
  • Scale test memakai XML SYNTHETIC, bukan export FigML asli.
  • Akurasi implementasi Angular akhir tidak diukur langsung (di luar scope fase 1); render probe bersifat honest-skip.
  • node --test test/ dijalankan: 779 test, 776 lulus, 0 gagal, 3 skip (browser/render probe honest-skip).
  • Security probe (XXE/entity/depth/`__proto__`/malformed) kini jadi regression test permanen di test/figml-contract.test.mjs.
